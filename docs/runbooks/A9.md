# A9: Autoloader schema evolution restart

Problem ID: A9. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

With addNewColumns, a new column makes the stream stop once by design.

## Who it affects

Data engineers.

## How to detect it

Update failed with an unknown-field / schema-evolution error.

## What to do

Recognize it as expected, restart once, confirm it recovered; escalate if it fails again.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Partly built. restart exists; error recognition missing
