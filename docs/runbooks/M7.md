# M7: Replays with new IDs

Problem ID: M7. Layer M: Data content problems.

## What happens

A producer resends old readings with fresh event_ids, so dedup by event_id misses them.

## Who it affects

Data engineers.

## How to detect it

Same (patient, itemid, event_ts, value) repeated.

## What to do

Report the replay window; content-based dedup check.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
