# M9: PHI in the wrong field

Problem ID: M9. Layer M: Data content problems.

## What happens

A name typed into free-text notes bypasses column masking.

## Who it affects

Data engineers and data analysts.

## How to detect it

Name / identifier detection on free-text columns.

## What to do

Keep free text out of Gold (notes are excluded today) and scan any new text column before exposure (C1).

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

Partly built. notes excluded from Gold; no scanner
