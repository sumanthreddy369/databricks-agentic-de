Problem ID: B3. Layer B: Delta Live Tables - Bronze, Silver, Gold.

OOM, executor lost, cluster can't start, GCP CPU quota exhausted.

## How to detect it

## What to do

Retry transient once; for quota/OOM, escalate with the exact error and a sizing recommendation.
