# O4: Counting history versions instead of entities

Problem ID: O4. Layer O: Analyst SQL correctness on Databricks SQL.

## What happens

fct_encounter_history has one row per version, so COUNT(*) without as_of counts transfers and status changes, not encounters.

## Who it affects

Data analysts.

## How to detect it

Aggregate on a history table without as_of.

## What to do

Use as_of, or count_distinct on the key; the tool flags the case in its result.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

A working tool or check exists in this project. aggregate_gold_table adds a note when a history table is aggregated without as_of
