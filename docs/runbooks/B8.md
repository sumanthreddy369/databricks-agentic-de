# B8: Silent row loss between layers

Problem ID: B8. Layer B: Delta Live Tables - Bronze, Silver, Gold.

## What happens

Bronze -> Silver -> Gold counts diverge beyond expected drops.

## Who it affects

Data engineers.

## How to detect it

Per-window reconciliation: Bronze rows = Silver rows + dropped + filtered.

## What to do

Report unexplained gap with the window; escalate.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
