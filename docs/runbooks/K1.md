# K1: Kafka broker / partition leader down

Problem ID: K1. Layer K: Servers down - outages and partial failures.

## What happens

Producers buffer, the pipeline stalls.

## Who it affects

Data engineers.

## How to detect it

Connection errors in pipeline events; zero progress with a healthy cluster.

## What to do

Separate 'broker down' from 'pipeline broken'; escalate to the platform owner, don't restart the pipeline in a loop.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. simulator producer retries; no broker check
