# N9: Undocumented tables and columns

Problem ID: N9. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

Missing table/column comments make analysts and the agent guess what a column means.

## Who it affects

Data engineers and data analysts.

## How to detect it

Gold tables or columns with empty comments.

## What to do

Report gaps; draft comments for an owner to review.

## Autonomy

Level L0 (L0: observe and report only).

## Status in this project

Not built yet - handle by hand.
