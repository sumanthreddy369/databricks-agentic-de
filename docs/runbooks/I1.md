# I1: GCS access failure

Problem ID: I1. Layer I: GCP infrastructure under Databricks.

## What happens

The Autoloader landing bucket returns 403 after a service-account or IAM change.

## Who it affects

Data engineers.

## How to detect it

Update failed with a storage permission error.

## What to do

Name the bucket and identity; escalate. No IAM changes by the agent.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
