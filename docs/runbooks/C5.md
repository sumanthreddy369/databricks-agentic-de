# C5: Small-cell re-identification

Problem ID: C5. Layer C: Governance - Unity Catalog masking, row filters, access.

## What happens

'How many 34-year-old female patients in Burn Unit?' = 1 identifies a person even with names masked.

## Who it affects

Data analysts.

## How to detect it

Result counts below a minimum cell size.

## What to do

Suppress or bucket small counts (e.g. <11) and say why.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

A working tool or check exists in this project. aggregate_gold_table suppresses groups under 11 patients; subtraction from totals is prompt-only
