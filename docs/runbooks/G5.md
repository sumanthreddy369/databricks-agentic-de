# G5: 'What changed?' debugging

Problem ID: G5. Layer G: Databricks SQL warehouse and Delta table maintenance.

## What happens

A Gold number moved and nobody knows why.

## Who it affects

Data engineers and data analysts.

## How to detect it

Table history (operations, versions) and lineage.

## What to do

Diff two versions of the table and explain the change with the operation that caused it.

## Autonomy

Level L0-L1 (L0: observe and report only; L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
