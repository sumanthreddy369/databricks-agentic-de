# J1: Traffic spike

Problem ID: J1. Layer J: Data overload - volume, bursts, skew.

## What happens

Mass-casualty event or shift-wide device reconnect sends 10x normal volume; backlog builds and Gold freshness collapses.

## Who it affects

Data engineers.

## How to detect it

Input rate vs rolling baseline; backlog and batch duration rising together.

## What to do

Report the spike and its source mix; scale workers within a pre-approved budget cap; protect Gold freshness first.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Not built yet - handle by hand.
