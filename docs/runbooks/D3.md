# D3: Secret / token expiry

Problem ID: D3. Layer D: Orchestration and platform - Workflows, Asset Bundles, secrets, the agent itself.

## What happens

DATABRICKS_TOKEN or the Anthropic key expires.

## Who it affects

Data engineers.

## How to detect it

Auth errors on agent calls.

## What to do

Name the exact secret scope/key to rotate; escalate.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. errors surface; no classification
