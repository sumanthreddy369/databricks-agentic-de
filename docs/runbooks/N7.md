# N7: Event contract version change

Problem ID: N7. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

The producer starts sending a new schema_version; old and new shapes mix in the stream.

## Who it affects

Data engineers.

## How to detect it

New schema_version values appearing in Bronze.

## What to do

Report versions seen and their share; confirm the pipeline handles both before the old one is retired.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. schema_version is in the envelope; nothing counts it yet
