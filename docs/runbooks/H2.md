# H2: Stale knowledge index

Problem ID: H2. Layer H: Databricks AI layer - Genie, AI Search, Agent Bricks, model registry.

## What happens

The Vector Search index lags the runbook source, so the agent cites an outdated runbook.

## Who it affects

Data engineers.

## How to detect it

Index sync status / last sync time vs source table.

## What to do

Trigger sync; warn in the answer that guidance may be stale.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).
