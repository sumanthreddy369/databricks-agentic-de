# O6: Reproducing a number someone saw earlier

Problem ID: O6. Layer O: Analyst SQL correctness on Databricks SQL.

## What happens

An auditor asks why a report said 42 yesterday; the table has changed since.

## Who it affects

Data analysts.

## How to detect it

Questions about a previous result or report.

## What to do

Query the Delta table as of the earlier version/time and explain the difference.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).
