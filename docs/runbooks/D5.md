# D5: Agent misbehaving

Problem ID: D5. Layer D: Orchestration and platform - Workflows, Asset Bundles, secrets, the agent itself.

## What happens

Remediation loop or paging storm.

## Who it affects

Data engineers.

## How to detect it

Escalation ceiling; notify_and_page count in audit log.

## What to do

Force escalation after 3 attempts; kill switch disables remediation.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

A working tool or check exists in this project. escalation ceiling, kill switch, anomaly detection
