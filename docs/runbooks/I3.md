# I3: GCP quota / capacity

Problem ID: I3. Layer I: GCP infrastructure under Databricks.

## What happens

No CPUs or IPs left in the region; clusters fail to start.

## Who it affects

Data engineers.

## How to detect it

Cluster start failure with a quota error.

## What to do

Escalate with the quota name and current usage (see B3).

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
