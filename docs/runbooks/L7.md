# L7: Same-second ties

Problem ID: L7. Layer L: Timestamps and matching events in time.

## What happens

Admit and transfer stamped in the same second; CDC order is ambiguous.

## Who it affects

Data engineers.

## How to detect it

Duplicate (key, event_ts) pairs in the CDC source.

## What to do

Add a tie-breaker (source sequence number) to sequence_by; report ties until then.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
