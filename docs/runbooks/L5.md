# L5: Format / precision mismatch

Problem ID: L5. Layer L: Timestamps and matching events in time.

## What happens

Epoch milliseconds vs seconds, string formats; parsing fails or lands in 1970 / year 50000.

## Who it affects

Data engineers.

## How to detect it

Parse failures and out-of-range years per source.

## What to do

Report the source and format; contract fix.

## Autonomy
