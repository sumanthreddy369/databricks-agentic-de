# M8: Encoding problems

Problem ID: M8. Layer M: Data content problems.

## What happens

Non-UTF-8 bytes in notes break JSON parsing.

## Who it affects

Data engineers.

## How to detect it

Corrupt records with decode errors (A3).

## What to do

Report the source and sample size.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
