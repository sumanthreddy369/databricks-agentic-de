# B4: CDC correctness

Problem ID: B4. Layer B: Delta Live Tables - Bronze, Silver, Gold.

## What happens

apply_changes with sequence ties, NULL keys, or events out of order gives a wrong current state (wrong unit, never-discharged patients).

## Who it affects

Data engineers.

## How to detect it

Reconciliation queries: encounters 'in-progress' far longer than plausible; status counts vs event counts.

## What to do

Report suspicious keys with evidence; propose fix. No data edits.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
