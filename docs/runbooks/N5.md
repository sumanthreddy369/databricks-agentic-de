# N5: Backfill after a bug fix

Problem ID: N5. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

Fixed logic must be applied to past data without double counting or disturbing live streams.

## Who it affects

Data engineers.

## How to detect it

A fix that changes historical results (e.g. the M4 physical-limits change).

## What to do

Draft the backfill plan (range, tables, compute, effect on Gold numbers); a human approves and runs it.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).
