# K6: GCS throttling or outage

Problem ID: K6. Layer K: Servers down - outages and partial failures.

## What happens

Autoloader reads fail with 429/503.

## Who it affects

Data engineers.

## How to detect it

Storage error class in pipeline events.

## What to do

Back off and retry; escalate if sustained.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Not built yet - handle by hand.
