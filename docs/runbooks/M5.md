# M5: Stuck sensor / flatline

Problem ID: M5. Layer M: Data content problems.

## What happens

The same value for hours looks valid to every range check.

## Who it affects

Data engineers.

## How to detect it

Zero variance over a window per device.

## What to do

Flag the device; exclude from trends until checked.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).
