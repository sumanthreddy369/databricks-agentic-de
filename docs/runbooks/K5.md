# K5: Databricks or GCP outage

Problem ID: K5. Layer K: Servers down - outages and partial failures.

## What happens

The agent's own monitoring calls fail, so it can see nothing.

## Who it affects

Data engineers.

## How to detect it

Its tools return errors / timeouts.

## What to do

Report status UNKNOWN, never 'healthy'; escalate after N failed checks.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

Partly built. API errors surface as tool errors; no explicit UNKNOWN state
