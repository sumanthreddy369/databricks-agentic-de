# B1: Data-quality drop spike

Problem ID: B1. Layer B: Delta Live Tables - Bronze, Silver, Gold.

## What happens

expect_or_drop (plausible_vital_value) suddenly drops many rows - device miscalibration, unit change (F vs C).

## Who it affects

Data engineers.

## How to detect it

failed_records per expectation vs rolling baseline (pipeline event log).

## What to do

Find the segment (unit, device, itemid); quarantine only if the cause is bounded; otherwise escalate.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

A working tool or check exists in this project. check_expectation_metrics (local + live; run against Databricks Free Edition) and quarantine_bad_records behind the approval gate
