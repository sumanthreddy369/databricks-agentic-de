# N8: New Gold table deployed without grants, masks, or row filters

Problem ID: N8. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

A new table reaches Gold before its governance does - e.g. fct_encounter_history needed the same unit row filter as fct_encounters, added by hand.

## Who it affects

Data engineers.

## How to detect it

Post-deploy check that every Gold table has its expected grants, column masks, and row filters.

## What to do

Block agent queries on the table and escalate until governance is applied.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Not built yet - handle by hand.
