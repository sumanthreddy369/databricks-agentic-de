# F2: Counts and aggregates on large tables

Problem ID: F2. Layer F: Data analyst questions over Gold.

## What happens

The DA tool returns raw rows capped at 500, so the model counts what it sees. 'How many ICU patients?' is wrong once there are more than 500.

## Who it affects

Data analysts.

## How to detect it

Truncation flag from the row cap.

## What to do

Use a governed aggregate tool (COUNT / AVG / GROUP BY computed in SQL), never count returned rows.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

A working tool or check exists in this project. aggregate_gold_table computes it in SQL (tested locally)
