# K2: Silent source

Problem ID: K2. Layer K: Servers down - outages and partial failures.

## What happens

The hospital interface engine or device gateway stops sending. Every job is green but no data arrives.

## Who it affects

Data engineers.

## How to detect it

Zero input rate during hours when traffic is expected (silence watchdog).

## What to do

Page the source owner: 'no events from X since T'. Silence must never read as healthy.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand. high priority
