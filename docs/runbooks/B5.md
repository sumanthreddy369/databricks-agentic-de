# B5: Full refresh needed

Problem ID: B5. Layer B: Delta Live Tables - Bronze, Silver, Gold.

## What happens

after a logic change or corruption. Full refresh truncates and recomputes tables.

## Who it affects

Data engineers.

## How to detect it

Human request or repeated reconciliation failure.

## What to do

Prepare the plan (tables, cost, downtime). Never execute - destructive actions are out of bounds by design.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

A working tool or check exists in this project. start_update pins full_refresh=false
