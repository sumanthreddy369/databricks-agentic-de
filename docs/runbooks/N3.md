# N3: Bad deploy - quality drops right after a release

Problem ID: N3. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

New pipeline code passes deploy but expectation failures or row counts change at once.

## Who it affects

Data engineers.

## How to detect it

Failure or metric change starting within minutes of a bundle deployment.

## What to do

Correlate the change with the deployment, report both, and recommend redeploying the previous version.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
