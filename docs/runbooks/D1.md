# D1: Scheduled job failure

Problem ID: D1. Layer D: Orchestration and platform - Workflows, Asset Bundles, secrets, the agent itself.

## What happens

reference_data_hourly or the healthcheck job fails.

## Who it affects

Data engineers.

## How to detect it

Jobs API run state.

## What to do

Repair/retry failed task once for transient errors; escalate otherwise.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Partly built. healthcheck exits non-zero on escalation; no repair tool
