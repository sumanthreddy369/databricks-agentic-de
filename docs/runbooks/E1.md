# E1: Model drift

Problem ID: E1. Layer E: ML - MLflow-tracked anomaly model served via ONNX.

## What happens

Vitals distribution shifts (new device, MIMIC-IV swap) so anomaly scores stop meaning anything.

## Who it affects

Data engineers.

## How to detect it

Feature drift (e.g. PSI) of live vitals vs training statistics logged in MLflow.

## What to do

Report drift; trigger retraining job; promotion needs human approval.

## Autonomy

Level L1-L2 (L1: recommend and escalate to a person; the agent changes nothing; L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Not built yet - handle by hand.
