# D2: Deployment drift

Problem ID: D2. Layer D: Orchestration and platform - Workflows, Asset Bundles, secrets, the agent itself.

## What happens

Someone edits a pipeline in the UI; workspace no longer matches the bundle.

## Who it affects

Data engineers.

## How to detect it

Compare deployed config vs databricks.yml/resources.

## What to do

Report the diff; redeploy only with approval.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
