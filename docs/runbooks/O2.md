# O2: Joins that change the answer

Problem ID: O2. Layer O: Analyst SQL correctness on Databricks SQL.

## What happens

Fan-out duplicates rows; a WHERE on the right table of a LEFT JOIN silently turns it into an inner join.

## Who it affects

Data analysts.

## How to detect it

Row grain before vs after a join.

## What to do

Only governed join templates with a declared grain.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

Partly built. the agent's tools can't join at all today, so it can't make this mistake - or answer join questions
