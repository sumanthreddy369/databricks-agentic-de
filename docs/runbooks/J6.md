# J6: Agent overload

Problem ID: J6. Layer J: Data overload - volume, bursts, skew.

## What happens

Huge tool results, long tool loops, or LLM rate limits during an incident when everyone asks at once.

## Who it affects

Data engineers and data analysts.

## How to detect it

Truncation flags, turn count, rate-limit errors.

## What to do

Size caps and retries already apply; summarize instead of dumping rows; queue non-urgent questions.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

Partly built. row/char caps, max_turns, retry exist; no queueing
