# K7: Partial failure

Problem ID: K7. Layer K: Servers down - outages and partial failures.

## What happens

The roster pipeline is down while the stream is up; Gold joins silently drop or misattribute rows.

## Who it affects

Data engineers.

## How to detect it

One pipeline stale while the other is fresh (B7 per pipeline).

## What to do

Report the dependency impact on Gold tables, not just 'pipeline X failed'.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
