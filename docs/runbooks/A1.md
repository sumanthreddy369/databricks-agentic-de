# A1: Consumer lag / backlog grows

Problem ID: A1. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

Micro-batches fall behind the topic; vitals reach Gold minutes late, so 'live' dashboards are stale.

## Who it affects

Data engineers.

## How to detect it

Streaming progress events: input rate > processed rate for N batches; batch duration trending up; Gold freshness (see B7).

## What to do

Report lag and trend; restart a stuck stream; recommend more workers or autoscaling (cost change needs approval).

## Autonomy

Level L1-L2 (L1: recommend and escalate to a person; the agent changes nothing; L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Not built yet - handle by hand. needs a get_stream_progress tool
