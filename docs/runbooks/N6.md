# N6: Missing environment secrets or volumes on first run

Problem ID: N6. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

A job deployed to a new workspace fails because its secret scope, UC volume, or schema was never created.

## Who it affects

Data engineers.

## How to detect it

First run fails with secret-not-found, volume or schema not found.

## What to do

List exactly which one-time setup steps are missing (see resources/workflows.yml header).

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. setup steps documented; no automated pre-flight check
