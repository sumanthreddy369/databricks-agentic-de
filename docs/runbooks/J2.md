# J2: One device floods the stream

Problem ID: J2. Layer J: Data overload - volume, bursts, skew.

## What happens

Firmware bug sends a reading every few milliseconds for one patient.

## Who it affects

Data engineers.

## How to detect it

Per-source / per-patient event rate far above the expected cadence.

## What to do

Name the device and patient key (masked); recommend throttling at the producer. Never drop its data silently.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
