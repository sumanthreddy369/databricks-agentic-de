# L3: Time zone mismatch

Problem ID: L3. Layer L: Timestamps and matching events in time.

## What happens

A source sends local time with no offset next to UTC sources.

## Who it affects

Data engineers.

## How to detect it

Systematic offset of whole hours between a source's event_ts and arrival time.

## What to do

Report the source and offset; fix at the contract, not by guessing.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
