# A8: Roster feed stale

Problem ID: A8. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

Autoloader gets no new provider files; dim_providers ages silently.

## Who it affects

Data engineers.

## How to detect it

Time since last file landed vs expected cadence (hourly).

## What to do

Page the feed owner with the last-seen file time.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
