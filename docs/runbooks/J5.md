# J5: Backfill competes with live data

Problem ID: J5. Layer J: Data overload - volume, bursts, skew.

## What happens

Reprocessing a week of history slows real-time vitals for clinicians.

## Who it affects

Data engineers.

## How to detect it

Backfill job running while freshness SLA degrades.

## What to do

Recommend running backfills on separate compute or off-peak; pause the backfill with approval.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
