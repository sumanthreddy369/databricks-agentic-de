# M4: Sentinel values

Problem ID: M4. Layer M: Data content problems.

## What happens

Disconnected devices send 0, -1 or 999. A heart rate of 0 passes plausible_vital_value (BETWEEN 0 AND 300).

## Who it affects

Data engineers.

## How to detect it

Spikes of exact sentinel values per device.

## What to do

Treat as missing, not as a reading; propose tightening the expectation.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

A working tool or check exists in this project. per-vital physical limits; SQL tested in DuckDB, pipeline never run
