# O3: Ratios computed by the model

Problem ID: O3. Layer O: Analyst SQL correctness on Databricks SQL.

## What happens

The model divides two counts in its head (percent of ICU patients with high HR) and gets arithmetic or denominator wrong.

## Who it affects

Data analysts.

## How to detect it

Answers containing percentages derived from two tool results.

## What to do

Compute ratios in SQL with an explicit numerator and denominator.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).
