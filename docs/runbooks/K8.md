# K8: Recovery surge

Problem ID: K8. Layer K: Servers down - outages and partial failures.

## What happens

After an outage the whole backlog replays at once and overloads everything (J1).

## Who it affects

Data engineers.

## How to detect it

Backlog size when a source or broker comes back.

## What to do

Staged recovery: raise capacity first, watch freshness, report time to catch up.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Not built yet - handle by hand.
