# O5: Reading a streaming window that is still filling

Problem ID: O5. Layer O: Analyst SQL correctness on Databricks SQL.

## What happens

The latest gold_live_vitals_by_unit window covers only part of its 15 minutes, so its counts look low.

## Who it affects

Data analysts.

## How to detect it

Window end after the latest data time.

## What to do

Say the current window is incomplete; compare completed windows only.
