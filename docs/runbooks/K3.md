# K3: Compute lost

Problem ID: K3. Layer K: Servers down - outages and partial failures.

## What happens

Cluster fails, GCP preemptible VMs reclaimed, executors lost mid-batch.

## Who it affects

Data engineers.

## How to detect it

Update FAILED / executor-lost events.

## What to do

Retry once (checkpoints make it safe); escalate if it repeats.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Partly built. restart_pipeline exists
