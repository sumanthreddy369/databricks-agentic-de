# C1: New PHI column without a mask

Problem ID: C1. Layer C: Governance - Unity Catalog masking, row filters, access.

## What happens

Someone adds e.g. phone or address to a Gold table.

## Who it affects

Data engineers.

## How to detect it

Schema scan of gold.* vs MASKED_COLUMNS + PHI name/value classifier.

## What to do

Block DA queries on the table and escalate to the data owner. Masking is never removed automatically.

## Autonomy

Level L2 (L2: act within guardrails - destructive actions wait for a named approver).

## Status in this project

Partly built. in-process masking exists for known columns; no new-column scan
