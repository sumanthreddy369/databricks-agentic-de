# N1: Dev and prod targets drift

Problem ID: N1. Layer N: Getting changes to production on Databricks - bundles, deploys, migrations.

## What happens

The dev bundle target works, prod fails - different catalog names, cluster policies, secret scopes, or permissions per target.

## Who it affects

Data engineers.

## How to detect it

databricks bundle validate per target; diff of resolved target configs; first-run failures in prod only.

## What to do

Report the exact config difference between targets; fixes go through the bundle and a reviewed deploy.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
