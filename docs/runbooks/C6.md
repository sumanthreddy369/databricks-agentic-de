# C6: Permission errors

Problem ID: C6. Layer C: Governance - Unity Catalog masking, row filters, access.

## What happens

Analyst or agent gets PERMISSION_DENIED after a grant change.

## Who it affects

Data engineers and data analysts.

## How to detect it

Error class on query.

## What to do

Diagnose which grant is missing and draft the GRANT; a human applies it.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
