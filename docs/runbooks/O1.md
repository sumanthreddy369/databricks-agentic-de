# O1: NULL semantics

Problem ID: O1. Layer O: Analyst SQL correctness on Databricks SQL.

## What happens

NOT IN against a list containing NULL returns nothing; COUNT(column) silently skips NULLs.

## Who it affects

Data analysts.

## How to detect it

Generated SQL patterns; counts that differ between COUNT(*) and COUNT(column).

## What to do

Build SQL from validated parts only (no free-form SQL); state when NULLs were excluded.

## Autonomy

Level L3 (L3: enforced in code on every request; no judgment call).

## Status in this project

Partly built. the agent can't write free-form SQL; NULL handling isn't reported in answers
