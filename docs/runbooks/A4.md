# A4: Duplicate events

Problem ID: A4. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

At-least-once delivery redelivers messages after retries/rebalances.

## Who it affects

Data engineers.

## How to detect it

Dedup drop count in silver_fct_vitals vs normal.

## What to do

Already handled by dropDuplicatesWithinWatermark; agent only alerts when the duplicate rate spikes (producer bug signal).

## Autonomy

Level L0-L1 (L0: observe and report only; L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. dedup exists in pipeline; no monitoring tool
