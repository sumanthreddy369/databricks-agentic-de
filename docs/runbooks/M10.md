# M10: Late corrections

Problem ID: M10. Layer M: Data content problems.

## What happens

A clinician corrects a vital hours later; the append-only table now holds both values.

## Who it affects

Data engineers and data analysts.

## How to detect it

Correction events / same reading id with a newer value.

## What to do

Model corrections explicitly; answers use the latest corrected value and say so.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
