# H3: Wrong model version live

Problem ID: H3. Layer H: Databricks AI layer - Genie, AI Search, Agent Bricks, model registry.

## What happens

The ONNX file served is not the version marked for production in the MLflow registry.

## Who it affects

Data engineers.

## How to detect it

Compare served model hash/version vs registry alias.

## What to do

Report the mismatch; redeploy with approval.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
