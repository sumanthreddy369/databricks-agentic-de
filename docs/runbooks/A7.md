# A7: Broker / auth failure

Problem ID: A7. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

Expired SASL credentials, network or firewall change; pipeline update FAILS.

## Who it affects

Data engineers.

## How to detect it

Update FAILED with a connection/auth error class.

## What to do

Classify the error; for auth, name the secret that needs rotation and escalate. The agent never handles credentials.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. check_job_status sees FAILED; no error classification
