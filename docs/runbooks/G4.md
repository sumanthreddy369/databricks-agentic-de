# G4: VACUUM vs audit retention

Problem ID: G4. Layer G: Databricks SQL warehouse and Delta table maintenance.

## What happens

Too-short retention destroys the time travel needed for audits and investigations.

## Who it affects

Data engineers.

## How to detect it

Table retention properties vs policy.

## What to do

Flag violations. Never run VACUUM below the policy retention.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).
