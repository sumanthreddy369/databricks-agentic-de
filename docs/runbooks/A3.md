# A3: Poison / malformed messages

Problem ID: A3. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

Bad JSON or wrong types land in _corrupt_record (Bronze keeps them).

## Who it affects

Data engineers.

## How to detect it

Corrupt-record ratio per batch vs baseline.

## What to do

Quantify, sample (masked) examples for the producer team, escalate if over threshold. Never edit raw data.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
