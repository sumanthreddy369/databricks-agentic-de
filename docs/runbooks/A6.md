# A6: Offset gap / retention expiry

Problem ID: A6. Layer A: Ingestion - Kafka/Redpanda stream and Autoloader roster feed.

## What happens

failOnDataLoss=false means expired Kafka data is skipped without failing.

## Who it affects

Data engineers.

## How to detect it

Offset discontinuities in stream progress; row-count gap vs producer count.

## What to do

Escalate immediately with the time range lost and a backfill plan. Data loss is never auto-remediated.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Not built yet - handle by hand.
