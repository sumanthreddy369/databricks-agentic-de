# J7: Join memory blow-up

Problem ID: J7. Layer J: Data overload - volume, bursts, skew.

## What happens

The stream-static join in gold_live_vitals_by_unit grows with fct_encounters until the driver runs out of memory.

## Who it affects

Data engineers.

## How to detect it

Driver memory and join size trend; OOM failures (B3).

## What to do

Recommend pruning to active encounters or a different join strategy.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).
