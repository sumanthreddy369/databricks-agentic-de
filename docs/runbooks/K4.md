# K4: SQL warehouse down

Problem ID: K4. Layer K: Servers down - outages and partial failures.

## What happens

Analyst questions fail.

## Who it affects

Data analysts.

## How to detect it

Warehouse state / statement errors.

## What to do

Tell the user plainly; no fallback to unmasked or stale local copies.

## Autonomy

Level L1 (L1: recommend and escalate to a person; the agent changes nothing).

## Status in this project

Partly built. live errors become tool errors
